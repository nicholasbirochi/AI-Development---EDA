# Netflix Daily Top 10 — Exploratory Data Analysis (EDA)

This repository contains a Jupyter notebook, `visualization.ipynb`, for an initial exploratory analysis of the Netflix Daily Top 10 dataset. The notebook loads `./data/netflix_daily_top_10.csv` and inspects column types, dataset size, missing values, date coverage, descriptive statistics, and several column distributions and records.

## Requirements

- Python 3
- Jupyter Notebook
- pandas and matplotlib

Install the notebook dependencies with:

```bash
pip install pandas matplotlib notebook
```

## Data

Place the CSV at `data/netflix_daily_top_10.csv`, relative to the notebook's working directory. The notebook reads that path directly. The CSV is included under `data/` in this repository.

## Run

Start Jupyter from the repository root:

```bash
jupyter notebook
```

Open `visualization.ipynb` and run its cells in order.
